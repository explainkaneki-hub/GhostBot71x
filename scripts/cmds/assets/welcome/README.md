# Welcome cards

Put your ChatGPT-created welcome card images in this folder.

- Recommended size: 1200x630 or 1080x1080
- Supported formats: PNG, JPG, GIF, WEBP
- Use a simple filename, for example `pink-pookie.png`
- In the group, run `.setwelcome card pink-pookie.png`
- Run `.setwelcome card list` to see available cards
- Run `.setwelcome card reset` to return to the remote default card

The bot sends the selected image with the member name, group name, member count, and join time in the message body.
